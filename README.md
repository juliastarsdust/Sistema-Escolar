
# Sistema Escolar

## Descrição
Projeto de banco de dados desenvolvido para organizar as informações de um sistema escolar.

O objetivo é separar os dados de alunos, responsáveis, disciplinas, matrículas, notas e faltas, evitando a duplicação de informações.

## Tecnologias utilizadas
- SQLite
- SQL
- GitHub

## Estrutura do banco de dados
O banco possui sete tabelas:

1. Alunos
2. Responsaveis
3. Aluno_Responsavel
4. Disciplinas
5. Matriculas
6. Notas
7. Faltas

## Arquivos
- 01_criacao_tabelas.sql: criação das tabelas (DDL).
- 02_insercao_dados.sql: inserção de dados (DML).
- 03_consultas.sql: consultas para testar o banco.

## Objetivo
Aplicar conceitos de normalização, chaves primárias, chaves estrangeiras e relacionamentos entre tabelas.
